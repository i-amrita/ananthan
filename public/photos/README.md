# Placeholder frames

These three files are **placeholders**, not photographs.

The real photographs are Ananthan's and have not been supplied yet, so nothing here is presented as
his work. Each file is a flat placeholder card with the word PLACEHOLDER written on it.

To publish real photographs:

1. Drop the image file into this directory (`public/photos/`).
2. Add or edit the matching entry in `src/content/photos/`. The `alt` field is required by the schema.
3. Set `draft: false` on the entry once the alt text is real.

The `/photography` route links out to `https://nambiar4.myportfolio.com`, which is where the copyright
for his photographs lives.
